## What was asked

The owner asked for a better engine panel, in which a click on an engine move previews it on the
board. The board shows that it is a preview with a `previewing` class. The decision was made then.
This record was written afterwards, from the code and from what was found then.

## What was done and why

The class is added and removed with `classList.toggle` in an effect, and the element's `className`
in JSX stays the fixed `board`. Chessground, which draws the board, puts classes of its own on the
same element. When React set `className`, it replaced the whole list and removed chessground's
classes, among them `cg-wrap`, which chessground's styles need to place the pieces. The pieces
disappeared from the board while this was being built, and came back with this change.

## Alternatives rejected

- Setting `className` from React, with `previewing` added when needed: removed chessground's
  classes, as above.

## Assumptions

None.

## When to revisit

If chessground stops putting classes on the element it is given, or if the board is wrapped in an
element of its own that can carry the class.
