# ADR-0008: No copyrighted books in the repository

Status: Accepted

## Context

Extraction must be tested against real books, but books are copyrighted, and
derived text can carry the same problem.

## Decision

- Automated tests use original synthetic books generated by test code.
- Real books stay outside the repository and are named by a local path only.
- Results from real books are recorded as aggregate numbers, without book text,
  titles, or extracted move lists.
- Files under `corpus/` and generated reports are git-ignored.

## Consequences

The public test suite cannot prove accuracy on real books. Each release needs a
local run against hand-checked books the maintainer legally owns.
